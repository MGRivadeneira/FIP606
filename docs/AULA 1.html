##Cargando datos en el ambiente Como rutina en el análisis de datos, uno de los primeros pasos es crear, cargar o importar el conjunto de datos en el entorno R. El formato más utilizado para almacenar datos en varias columnas es el marco de datos. Existen varias formas de cargar datos y crear marcos de datos, dependiendo del tamaño del conjunto y del formato disponible. A menudo, sólo queremos crear conjuntos de secuencias o números, lo que puede hacerse con las funciones básicas que ya hemos visto, sin necesidad de cargar un fichero externo. Los datos suelen organizarse en hojas de cálculo, que deben importarse al entorno. A continuación se presentarán las formas más comunes de introducir datos en R para su análisis.

##Primer Paso: Instalación de R y RStudio

  1. Instalación de R R es el lenguaje y entorno de software que necesitas para llevar a cabo análisis estadísticos. Para comenzar, debes instalar R en tu computadora:
  1. Descargar R:

Visita el sitio web oficial del Proyecto R: CRAN (The Comprehensive R Archive Network). Selecciona el enlace de descarga correspondiente a tu sistema operativo (Windows, macOS o Linux).

  1. Descargar RStudio:

Visita el sitio web oficial de RStudio: RStudio. Selecciona la versión gratuita de RStudio Desktop correspondiente a tu sistema operativo.

##Link para instalacion de R y de R Studio (https://posit.co/download/rstudio-desktop/)

Instalación de paquetes puede ser hecha a traves de menu: Tools > Install packages…, o tambien por:

Codigo 
#install.packages(nombre del paquete de interes )

Carga de paquetes

Después de la instalación, puede cargar los paquetes utilizando la opción “packages”, debe introductir el nombre del programa de interés en la barra de búsqueda y luego seleccionar o puede utilizar el comando “library”. Importante recordar que antes de iniciar cualquier trabajo en R, es necesario cargar los paquetes de interés.

Codigo 
library(tidyverse)
library(remotes)

Remocion de mensajes de alerta

La eliminación de los mensajes de advertencia que emiten algunos paquetes facilita la visualización de la información.

Codigo 
warning(FALSE)
