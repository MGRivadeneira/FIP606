Analisis de regresión

El análisis de regresión es una técnica estadística utilizada para investigar la relación entre variables mediante la construcción de una ecuación (un modelo). En general, esta técnica puede utilizarse con diversos fines, entre ellos: describir la relación entre variables para comprender un proceso o fenómeno; predecir el valor de una variable a partir del conocimiento de los valores de las demás variables; sustituir la medición de una variable por la observación de los valores de otras variables; controlar los valores de una variable dentro de un intervalo de interés.

Regresión

Slope (pendiente) diferente al ángulo 0.

Anova

Para variables categóricas/comparación.

## Analisis de regresión

El análisis de regresión es una técnica estadística utilizada para investigar la relación entre variables mediante la construcción de una ecuación (un modelo). En general, esta técnica puede utilizarse con diversos fines, entre ellos: describir la relación entre variables para comprender un proceso o fenómeno; predecir el valor de una variable a partir del conocimiento de los valores de las demás variables; sustituir la medición de una variable por la observación de los valores de otras variables; controlar los valores de una variable dentro de un intervalo de interés.

### Regresión

Slope (pendiente) diferente al ángulo 0.

### Anova

Para variables categóricas/comparación.
