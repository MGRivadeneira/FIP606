Frecuencia de clase

chisq.test

Realiza pruebas de tablas de contingencia chi-cuadrado y pruebas de calidad de ajuste.

Codigo 
q <- table (survey$residue, survey$species)
chisq.test(q)

    Pearson's Chi-squared test with Yates' continuity correction

data:  q
X-squared = 1.1997, df = 1, p-value = 0.2734

Para frecuencias mas bajas

fisher.test

Realiza la prueba exacta de Fisher para probar el nulo de independencia de filas y columnas en una tabla de contingencia con marginales fijos.
