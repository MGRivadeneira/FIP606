Regresión no lineal

La regresión no lineal es un método para hallar un modelo no lineal de la relación entre una variable dependiente y un conjunto de variables independientes. A diferencia de la regresión lineal tradicional, que se limita a estimar modelos lineales, la regresión no lineal puede estimar modelos con relaciones arbitrarias entre variables independientes y dependientes. Para ello se utilizan algoritmos de estimación iterativos.

EC50 con el paquete DRC

El control efectivo del 50% de inhibición del crecimiento (EC 50) es un estadístico estándar para evaluar las relaciones dosis-respuesta. Existen muchos paquetes de software estadístico para estimar las relaciones dosis-respuesta, pero recientemente se ha utilizado un paquete de código abierto (“drc”) en R. Este paquete es muy adaptable, tiene muchos modelos para describir las relaciones dosis-respuesta y la flexibilidad para describir las relaciones horméticas y la EC 50 absoluta y relativa. Referencia: https://apsjournals.apsnet.org/doi/full/10.1094/PDIS-06-17-0873-SR

Codigo 
library(drc)

drc1 <- drm(GC_mean ~ Dose, data = FGT152,
    fct = LL.3())
plot(drc1)
